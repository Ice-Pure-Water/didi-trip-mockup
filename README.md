# 行程单样张生成器

一个静态中文行程单样张页面，用于样式展示和虚构行程演示。

## 在线访问

**访问地址：[https://ice-pure-water.github.io/didi-trip-mockup/](https://ice-pure-water.github.io/didi-trip-mockup/)**

无需安装，直接通过浏览器打开。

## 本地使用

下载仓库后，直接用浏览器打开 `index.html`，或在仓库目录启动静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 项目结构

- `index.html`：页面、样式与浏览器端交互。
- `assets/`：页面使用的图片资源。
- `AGENTS.md`：仓库维护规范。

项目无需安装依赖或执行构建。线上页面由 GitHub Pages 托管，发布仓库根目录中的静态文件。

## 使用说明

样张仅用于演示，不作为真实行程或报销凭证。请使用虚构数据，勿向仓库提交真实个人信息或包含真实身份信息的生成文件。
